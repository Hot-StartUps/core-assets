# 📂 Fundraising Data Room Checklist
*Version 1.0 - Open Source Standard*

Use this checklist to prepare your documentation before reaching out to investors.

### 1. Corporate Documents
- [ ] Certificate of Incorporation
- [ ] Updated Cap Table (Excel or Ledgy/Carta link)
- [ ] Articles of Association

### 2. Financials
- [ ] P&L Statement (Last 12-24 months)
- [ ] 3-Year Financial Projections (Model)
- [ ] Burn rate and Runway analysis

### 3. Product & IP
- [ ] Tech Stack Overview
- [ ] Intellectual Property (IP) Assignment Agreements
- [ ] Product Roadmap (Next 12 months)

---
*Contribute: If you think a document is missing, open a Pull Request.*
