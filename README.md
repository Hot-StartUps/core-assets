# 🏛️ Open Assets
### The Open-Source Infrastructure for Startups.

Welcome to the central intelligence hub. This repository is a shared operating system designed to eliminate fragmentation and provide high-quality, open-source resources for the startup ecosystem.

---

## 🛡️ Core Principles
*   **Give-First, Open-Source Always:** We build shared assets to help everyone grow.
*   **High-Signal, Low-Friction:** Direct access between Founders and Investors, optimized for efficiency.
*   **Horizontal Networking:** Expertise over titles.

## 📂 What's Inside?
*   **`/legal-frameworks`**: Standardized investment documents (SAFE, Term Sheets).
*   **`/fundraising-ops`**: Data room checklists and fundraising playbooks.
*   **`/market-intelligence`**: Collective mapping of the VC landscape.

## 🤝 How to Participate
This is a living project. You can contribute by:
1.  **Exploring** the assets to accelerate your startup or investment process.
2.  **Improving** documents via Pull Requests.
3.  **Discussing** strategy on our Discord server.
